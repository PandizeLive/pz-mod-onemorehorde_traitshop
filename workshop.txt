description=[h1]PLAYING WITH OMH: HORDE NIGHT?[/h1]
description=
description=Trait Shop is enabled by default. Find [b]Enable Trait Shop[/b] in Horde Night's Run Options. Using purchased traits, removals or a Prestige creation bonus keeps it enabled for the affected character or faction.
description=
description=Trait Shop applies a [b]x0.50 score multiplier[/b], combined multiplicatively with other score modifiers. Horde Night rewards and default-or-harder settings can remain Official. Easier settings, enabling negative removal or switching away from Horde Night reward mode make the affected run unofficial.

description=Characters created before Horde Night could verify their creation remain playable, but their runs are Unverified. Create a new character and reset the run for a fresh eligibility check; fixing settings or respawning does not erase an old run's flags.
