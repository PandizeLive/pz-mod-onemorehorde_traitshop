# Checkpoint 7 — short solo test

Install **Trait Shop 0.7.0** with [OMH_TraitShop.cmd](../OMH_TraitShop.cmd), option **1**, then launch through Steam. If using Horde Night, install **0.6.14** through its OMH.cmd too. Use a disposable save.

1. New Sandbox: **Hybrid**, Zombie XP **7450**, Night XP **0**, Prestige interval **5**, retention **30%**.
2. Choose **Unemployed, no traits**; enter and kill one zombie: **Level 15, Prestige 3**.
3. Die. Choose Unemployed again: creation shows **+3 Prestige points**.
4. Back out and reopen creation: the bonus stays **3**.
5. Enter without traits: **Level 1, Tokens 11, Prestige 1**.
6. Save, quit and reload: those balances stay unchanged.
7. Without earning XP, die and recreate identically: **+1 creation point, Tokens 9, Prestige 0**.
8. Die/recreate once more: **no bonus, Tokens 8, Prestige 0**. Quit and report pass or the failed step.

Keep Character Free Points and the other reward settings at their defaults. This intentionally accelerated test is unofficial. After the result, review console.txt for the exact loaded build and settlement diagnostics. Real dedicated pre-spawn transport remains a separate short test after publishing both matching builds.
