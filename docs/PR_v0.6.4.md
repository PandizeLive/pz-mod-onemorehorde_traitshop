# Configure Tokens and Prestige earned from Trait Levels

Expose Tokens per Level (default 1) and Prestige Level Interval (default 5) under a Level Rewards sandbox heading. Apply changed values only to future earned levels; preserve past balances and prevent repeated interval changes from duplicating Prestige entitlements. Track actual earned Tokens so feedback and tooltip totals remain correct after custom rewards and spending.
