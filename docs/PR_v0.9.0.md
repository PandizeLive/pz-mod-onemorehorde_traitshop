# Trait Shop v0.9.0: Run Options and persistent scoring safeguards

A clean character can now opt out of Trait Shop through Run Options before confirming or receiving benefits. Purchases, Prestige and unofficial progression retain their scoring consequences across resets, reconnects, faction changes and addon removal. Characters created before Horde Night could verify them remain playable with unofficial scores; a new verified character can begin a qualifying run.

Moves Checkpoints and Difficulty Settings into Run Options, adds server-authoritative purchase/reward access gates, and previews the existing multiplicative score modifiers. The paired versions are Trait Shop 0.9.0 and Horde Night/Cure Defense 0.6.16. See the checkpoint report for validation evidence and the remaining live acceptance limits.

Validation: Trait Shop regression suites, core authority/UI checks, native Kahlua compilation and three dedicated-server save/restart cycles passed. The separate website policy update passes 36 tests and needs deployment before public release. Human client/faction acceptance remains pending.
