# Complete Prestige creation bonuses and retention

Prestige previously accumulated for the next life without affecting character creation. The creation screen now includes that bonus, and successful entry grants unused points as Tokens and retains 30% by default. Cancellation and repeated entry leave the one-time transaction intact.

Adds the Prestige sandbox section, account/slot creation previews, SP menu persistence and origin tracking for inherited custom earnings. The companion Horde Night 0.6.14 policy reviews retention and inherited benefits. Older saves preserve entitlements; a pre-patch SP save already at creation may receive its previously unpreviewed bonus as unused Tokens on that first entry.

Validation: native Kahlua lifecycle, reward, shop and creation-screen fixtures; companion policy/score regressions; isolated dedicated disk lifecycle probe. Live creation UI and dedicated pre-spawn transport remain owner acceptance checks. No external publication, install or mirror is implied by this source patch.
